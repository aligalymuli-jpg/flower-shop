# 🌸 FlowerShop – Интернет-магазин цветов

## 📋 Бизнес-задача
> Автоматизировал приём заказов для цветочного магазина в Алматы, внедрив отправку корзины в WhatsApp, управление ассортиментом через админ-панель и динамическую фильтрацию букетов.

## 🚀 Демо
[![Живой сайт](https://img.shields.io/badge/🌐-Перейти_на_демо-ff6b6b?style=for-the-badge&logo=vercel&logoColor=white)](https://flower-shop-almaty.netlify.app/)

> **Примечание:** демо использует локальное хранилище (localStorage) для стабильной работы без внешнего API. В коде есть полная интеграция с REST API.

## 🛠️ Стек технологий
- **React 18** + **Vite** – быстрая сборка и компонентная архитектура
- **React Router v6** – SPA с навигацией и страницей 404
- **Context API** – глобальное состояние (цветы, корзина, фильтры)
- **CSS переменные** – адаптивный дизайн, светлая/тёмная темы
- **Кастомные хуки** – `useForm`, `useFilter`, `useModal`, `useFetch`
- **Jest + React Testing Library** – модульные тесты (покрытие 9 тестов)

## ✨ Функциональность
- ✅ **Каталог букетов** – карточки с ценой, лайками, кнопками «Купить», «Редактировать», «Удалить»
- ✅ **Фильтрация** – поиск по названию и слайдер цены (оптимизировано через `useMemo`)
- ✅ **Управляемая форма** – добавление и редактирование букетов с валидацией в реальном времени
- ✅ **Корзина** – добавление, изменение количества, удаление, отправка заказа в WhatsApp
- ✅ **Избранное** – сохранение любимых букетов в localStorage
- ✅ **Тёмная тема** – переключатель с сохранением выбора
- ✅ **Таймер скидки** – обратный отсчёт с возможностью сброса
- ✅ **Адаптивность** – корректное отображение на мобильных, планшетах, десктопе
- ✅ **Тестирование** – 9 тестов для хуков и компонентов (все проходят)

## 🧩 Кастомные хуки (демонстрация 6-й лабы)
- `useForm` – управление состоянием формы, валидация (название ≥3, цена >0, описание ≥5)
- `useFilter` – фильтрация массива с кэшированием через `useMemo`
- `useModal` – открытие/закрытие модального окна
- `useFetch` – выполнение HTTP-запросов с индикацией загрузки и ошибок
